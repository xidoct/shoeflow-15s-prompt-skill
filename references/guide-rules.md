# 用户指定 Seedance 指南执行规则

依据：用户于2026-10-28提供的《Doubao Seedance 2 prompt.docx》。本文件是便于执行的提炼，完整文本与来源摘要见 [guide-source.md](guide-source.md)。如与泛用提示词模板有差异，采用用户指定指南；用户本次明确要求优先。指南中的案例是写法示范，不是每条视频必须包含的内容。

## 本技能采用的任务句式

用户已明确要求：参考视频仅用于分析，最终提示词不能引用它，动作和运镜必须直接分析并写出来。因此，原文关于视频引用、严格编辑和延长的句式保留为背景资料，不进入本技能成稿。

生成提示词从图片绑定和具体画面开始，例如“将图片1中的产品定义为商品甲……”后直接描述实际观察到并按需求改编的场景、人物行动和拍摄方式。不能以“参考视频1”“保留原片动作”等句子把分析工作交回生成模型，也不能换成“示例中的镜头”这类隐式引用。

每个镜头应让未见过原片的生成模型也能理解：谁从哪里开始、做什么连续动作，摄影机处于什么位置、以什么景别跟随、何时停下或切镜，谁在何时说什么。用人物动作触发镜头和对白交接，避免只列空泛的“自然手持”“节奏一致”。只写确实观察到或用户明确要求的细节。

产品图和其他实际用于生成的图片仍按指南明确编号与职责。无需把原视频、截取片段或原音轨加入素材清单。总时长、图片上限及生成设置采用目标入口实际支持的信息，不从原文的视频输入说明推导本任务能力。

## 主体与素材

- 原文“定义主体”：用2–3个稳定静态特征唯一识别主体；定义后始终用同一标签，避免“他/另一个人”反复切换造成歧义。
- 多份素材指向同一主体时统一绑定。商品多角度图不等于多个商品；人物多视图可能导致身份混淆，与商品多角度资料不能一概而论。
- 已定义主体用固定标签；未定义的简单场景可用“主体名@图片N”明确绑定。不要用内部Asset ID代替图片/视频编号。
- 图片编号遵循实际或明确约定的生成上传次序，分析用视频不占图片编号；如目标界面提供图片引用标签，使用它的真实标签，不编造引用语法。
- 用户仅上传产品图时不强迫补齐指南的4–5份推荐配置。补人物图、场景图、音频只有在当前目标确有需要时才提出。
- 人物高度一致性有要求而现图人脸过小时，按指南建议独立面部特写加全身照；不要宣称已经从拼图获得充分身份信息。

## 分镜与镜头

原文“使用分镜时序”：复杂视频按“镜头1、镜头2、镜头3”组织。每镜推荐顺序为：

1. 运镜或镜头切换方式。
2. 核心主体动作与表情。
3. 所处位置或空间变化。
4. 对应音效、人声或音乐。

默认依据事件安排节奏，不强制写“0–3秒、3–5秒”；指南明确提示精确时间支持不稳定。分析记录仍保留源片时间码方便核对，用户要求的总时长仍应遵守。用户明确要求秒级脚本时可以给出规划，但不能保证模型逐秒执行。

一个镜头尽量只指定一种主运镜。轻微手持质感是这次运动的拍摄方式；不要另加互相冲突的机械推拉摇移。某些指南案例含复合运镜，不应反过来覆盖其明确的简化建议。

动作写具体部位、幅度、速度、力度与过渡；情绪用看向、停顿、嘴角、手部等可见表现承载。优先连续可执行动作，不改掉用户要求或原片关键行为。不要把简单产品展示扩写成复杂戏剧。

## 声音与文字符号

| 内容 | 指南符号 | 写法 |
| --- | --- | --- |
| 台词 | `{}` | 人物甲先说{这双配色挺好看。}；人物甲说完后，人物乙回答{我也喜欢这个颜色。} |
| 音效 | `<>` | <鞋底落地的轻响> |
| 音乐 | `（）` | （低音量轻音乐） |
| 画面字幕 | `【】` | 【用户已确认的字幕内容】 |

示例只解释语法，不作为固定品牌文案。只写当前作品需要的声音项；无音乐就不添加音乐。台词语言统一，专有名词除外，小语种标明语种。标签和导演指令不能作为台词读出。双人对白每句明确归属、顺次交接，画外音与出镜者区分；这些操作能减少歧义，不能保证生成绝不重叠。

字幕、广告语若需要，写内容、出现时机、位置、方式和必要颜色风格；若不需要，加简明“无字幕”即可。避免“禁止任何文字/Logo”与“保留产品原字样/标识”冲突：把限制限定为新增字幕、平台水印和无关标志。

## 风格、画质和篇幅

原文进阶公式为“精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件”。它是信息组织参考，不要求每镜机械填齐八栏。

源片纪实时就写具体纪实拍摄条件；不要因为示例写“电影质感”就把真实街拍改成广告棚拍。画质词不等于分辨率设置，禁止用“4K”暗示480P输出会变成4K。描述简洁、指代清晰，无互斥特征；不把长剧本和冗余解释整段塞入提示词。
