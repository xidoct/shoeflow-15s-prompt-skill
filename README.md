# Hypit 参考复刻提示词

上传参考视频、产品图，再简单说明需求。技能按Hypit的参考分析方法拆解原片，结合产品外观，按照指定的Doubao Seedance 2指南输出可以直接复制的生成提示词。

**参考视频只用于分析。** 最终提示词会具体写出人物动作、机位、运镜、切镜、对话与声音节奏，不出现“视频1”“照原片”“运镜同参考”等依赖。生成时使用产品图及另行指定的模特或场景图片即可。

## 使用

将仓库下载到支持技能目录的Agent环境，并将目录命名为 `hypit-prompt`，让Agent加载根目录的 [SKILL.md](SKILL.md)。也可以克隆：

```bash
git clone https://github.com/xidoct/shoeflow-15s-prompt-skill.git hypit-prompt
```

然后提供参考视频、产品图和需求，例如：

> 使用 hypit-prompt 分析这个视频，把产品换成我的图片，保留人物互动和镜头节奏，只输出提示词。参考视频仅用于分析，提示词里直接写清动作与运镜。

技能默认只返回完整、可复制的提示词。需要拆分生成时，每段提示词独立完整；时长根据内容与用户要求确定，不固定为15秒。

## 兼容环境

技能采用普通Markdown指令和相对路径，不绑定Codex、特定操作系统或API供应商，也不要求必须安装Hypit。

- Agent具备视频、图片和音频理解能力时，直接分析实际素材。
- 有Hypit或其他媒体工具时，可结合元数据、抽帧和已核对的转写进行分析。
- 使用普通模型API时，由调用方加载 `SKILL.md`、`references/guide-rules.md` 和 `references/media-analysis.md`，并通过目标API支持的方式提供媒体。需要核对指南细节时再加载 `references/guide-source.md`。
- 仅传入技能名称或本地文件路径，远程模型不会自动获得文件内容。缺少媒体读取能力时，需要宿主提供相应能力或分析结果。

本技能不提交视频生成、不调用随变、不启动Studio，也不自动使用付费生成服务。

| 文件 | 用途 |

## 编写原则

先观察原片，再决定保留与替换哪些关系。人物台词归属清楚、轮流接话；摄影机动作具体，避免机械堆叠运镜。产品描述只使用图片可见信息及用户确认事实，不推断性能、价格或优惠。

遵循指定指南的主体标签、“镜头1、镜头2”分镜和声音符号写法；源时间码用于分析，不默认强制每镜精确秒数。产品图仍明确编号，商品本身的标识与不需要的服饰标识分别处理。

指南来自用户提供的《Doubao Seedance 2 prompt.docx》，保留其文本供核对；本仓库不将其标为已核实的最新官方版本。用户明确要求的“成稿不引用视频”优先于指南原文中的视频引用示例。
