# ShoeFlow 15 秒提示词工作台

独立运行的本地软件：口播文案 → 大语言模型分镜 → 每组最多 15 秒的完整 Seedance 提示词 → 手动复制。不会调用视频生成接口，不包含视频拼接。

## 启动

安装 Node.js 22.19 或更新版本，在此目录运行 `npm install`，然后 `npm start`，打开 http://127.0.0.1:4174 。Windows 可双击 `start.cmd`。不依赖原 ShoeFlow 项目运行，不需要 FFmpeg 或视频 API Key。

## 使用

1. 展开模型设置，填写兼容 Chat Completions 的 LLM 地址、Key、模型名称。生成分镜会调用此服务；支持 SSE 流式接收，页面完成后展示结果。
2. 输入文案，上传商品图和人物参考图，并选择衔接方式。图片会发送给配置的视觉大模型；未上传时可手动设置素材数量。
3. 点击生成，结果按任务保存到本目录 `tasks/`，左侧可重新打开，页面支持复制每组或导出 JSON。
4. 在视频平台按每组素材清单顺序再次上传图片，再复制对应提示词。第二组起自行获取上一组真实尾帧。严格模式只传尾帧并设为首帧；参考模式传尾帧加该组需要的原图。
5. 时长、画幅等仍需在视频平台单独设置。最多15秒，不会强行凑满15秒。编辑完整分镜JSON后可以重新分组，另存为新任务，旧任务不会覆盖。

提示词组装沿用主软件的完整 Ark 文本内容，包括素材编号、全片风格、背景、逐镜时间线、原文对白、表演、声音和衔接。实际图像和平台参数不是文字，不能通过复制提示词传入。人物素材推荐使用有相应用途授权的个人形象。默认普通居家手机带货风格。

真人感规则采用克制的日常带货表演：眼神和轻微面部变化跟随话意，商品动作与卖点同步，每镜只安排一条有目的、能完成的简短动作链。不会强制三个动作或固定情绪曲线，也不会为普通带货虚构戏剧冲突和夸张情绪。

设置（包括Key）保存在当前浏览器；任务文件不包含LLM配置。浏览器刷新不影响已保存任务。尚未完成的生成在服务重启后不会自动恢复。历史任务不会自动删除，请备份 `tasks/`；可在软件停止后手动删除相应任务JSON。

## 视觉参考

支持最多8张商品图和1张人物图，JPG/PNG/WEBP，每张最多5MB，请配置支持多模态 Chat Completions 的视觉模型。请求会包含图片本身，不只发送文件名；图片随任务保存，历史任务可以恢复。参考图约束外观，不能替代文案中的产品事实；系统要求不推断材质、性能、人物身份，不复制原图的门店和摄影灯背景。模型仍可能出错，生成后检查再使用。
